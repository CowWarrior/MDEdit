# Welcome to MDEdit

Thanks for installing MDEdit — a lightweight, dedicated desktop editor for writing Markdown on
Windows. This page doubles as your release notes: it opens automatically after installing an
update, so you always know what's new.

## Recent changes

### Version 1.0.3

- Tables now display as real grids in WYSIWYG mode — sized columns, a bold header row, and your alignment choices honoured — reverting to source whenever your cursor is inside one.
- WYSIWYG now shows your text in a proper document font, while code and any Markdown revealed at the cursor stay fixed-width.
- Bullet, numbered and task lists, blockquotes and headings now apply to every line you have selected, rather than only the first — press once to mark the whole selection, press again to clear it.
- Numbered lists count properly down the selection, 1, 2, 3.

### Version 1.0.2

- Added emoji shortcodes — type `:joy:`, `:rocket:` or any of around 240 others and it becomes the emoji as you write.
- Added task lists, which show as tick boxes you can toggle from the toolbar.
- The status bar now shows the document's size, its character count, and how much text you have selected.
- Corrected the version number shown in Help → About.

### Version 1.0.1

- Added highlighting, superscript, subscript and underline.
- Added Word's shortcut keys for underline (Ctrl+U), superscript (Ctrl+Shift++) and subscript (Ctrl+Shift+_).
- The formatting toolbar has been reordered to suit.
- Ctrl+I now italicises reliably.

### Version 1.0.0

- Added a Recent Files list to the File menu, keeping the ten documents you opened most recently.

### Prior versions

Not tracked.
