# Emoji shortcode → World Anvil icon, used only by Edit → Copy as BBCode (BBCodeConverter).
#
# World Anvil refuses to save an article containing emoji, so every emoji is exported as an icon
# instead. One "shortcode<space>replacement" pair per line:
#   - a Font Awesome or RPG-Awesome class ("fa-solid fa-fire", "ra ra-aura"), which the converter
#     wraps as "[section:<class>] [/section]" — Grandmaster tier and above;
#   - or a literal tag starting with '[', emitted as-is — World Anvil's free checklist icons.
#
# Keys are Emoji.txt shortcodes, and only the first-listed name of each emoji is ever looked up:
# aliases (+1, -1) resolve through their emoji to it, so they need no line of their own. A shortcode
# with no line here exports as ":shortcode:" text. Every Font Awesome name was checked by pasting it
# into a World Anvil article (2026-11-24); ok_hand, fox, panda, penguin and snail had no working icon,
# and ok, new and top no sensible one. Icons are single-colour, so the coloured hearts all share one.
# Blank lines and lines starting with '#' are ignored.
